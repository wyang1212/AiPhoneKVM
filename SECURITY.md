# Security

Do not include credentials, private endpoints, pairing tokens, device addresses, personal screenshots or unredacted logs in a public issue. Report sensitive findings privately through GitHub's private reporting mechanism if enabled; otherwise contact the repository maintainer before disclosing sensitive evidence. For non-sensitive defects, give the version, sanitized steps, expected result and observed result.

Examples in this repository are intentionally invalid and contain no supported public backend. Network/AI operation requires explicitly configured services. Keep the HTTP interface authenticated and restrict network exposure. A successful HID send is not proof of the target's final state.
