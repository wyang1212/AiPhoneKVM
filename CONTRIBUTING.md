# Contributing

Preserve upstream copyright notices, GPL terms and third-party licenses. Mark modified upstream files clearly and describe material changes in NOTICE.md. Test only against devices and services for which you have authorization. Add a regression for behavior-changing fixes, and record what was actually run.

Keep credentials, personal service addresses, device identifiers, signing keys, local build output and private test evidence out of commits. Use `example.invalid` and explicit test fixtures. Public screenshots must come from clean test state, not a developer's saved account or device list.

Build and source packaging commands are documented in README.md. A source release must include the exact source used for its APKs and the relevant license texts. Do not claim hardware or model compatibility from a successful build or mocked screenshot.
